Real reports

What telltale printed.

These are not mock-ups. Each report below is what telltale wrote for a machine in the project's Docker test lab: the HTML report, the terminal output and the JSON, as they came out.

CI makes them again for every release, with that release's telltale, so they show what the current version prints. The machines' names are made up. Everything planted on them is a harmless stand-in written for the lab: it leaves the traces a real backdoor would, and its call-outs only reach a container on a network with no way out.

The stories are read from reports/index.json, with a little JavaScript. The reports themselves are linked below.

    files02, with a snapshot: the HTML report, the terminal output, the JSON

    files02, without a snapshot: the HTML report, the terminal output, the JSON

    web01, with a snapshot: the HTML report, the terminal output, the JSON

    build03, a clean machine, with a snapshot: the HTML report, the terminal output, the JSON

    telltale is released under the Apache License 2.0.

    The lab and the scripts that make these reports are in the repository: lab/ and scripts/site-reports.sh.
