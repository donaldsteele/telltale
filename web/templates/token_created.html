Your new token: {{.Name}}

This is the only time the token is shown. telltale keeps only a hash of it, so it cannot show it again; if you lose it, revoke it and make another.

Token 
{{.Token}}

  1. On the computer where your AI assistant runs, save the token in a file only you can read. For example, make the file with:

    Command 
    install -m 600 /dev/null ~/.telltale-token

    then paste the token into it. telltale mcp refuses a token file that other users can read.

  2. Add this command to your MCP client's configuration as a stdio server, with the token file's full path in place of /home/you/.telltale-token. MCP clients start it without a shell, so most do not expand ~ themselves; telltale mcp does expand a leading ~/.

    Command 
    telltale mcp --server {{.Server}} --token-file /home/you/.telltale-token --fingerprint {{.Fingerprint}}

    The fingerprint is this server's HTTPS certificate. telltale mcp talks only to a server with exactly that certificate.

The assistant can read every machine's reports and start visits, at most one a minute per machine. It can never change a snapshot or accept anything. Text from monitored machines can try to give it instructions, so it is told never to follow such text and never to run fix commands.
