First run: set the admin password

This server has no admin password yet. The server will hold the key that logs in as root to every machine you enrol, so choose a long password and keep it somewhere safe.

To show that you are the person who started the server, type the one-time setup code it printed when it started. It is in the terminal you started it from, or in its log (journalctl -u telltale).
